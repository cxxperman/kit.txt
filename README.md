# kit.txt

Общая основа для приложений dev.txt™: Kapsula, Aura, Maska (для Discord), Arkada (для Steam), лаунчера core.txt и всего, что появится позже. Здесь две вещи:

- **Токены дизайна** — цвета, стекло, радиусы, шрифты и движение в одном файле. Из него собираются готовые файлы для C# и CSS.
- **Хаб** — один локальный канал, через который приложения видят друг друга, сообщают состояние и передают команды.

## Токены

Единственный источник — [tokens/tokens.json](tokens/tokens.json). Руками правится только он.

```bash
node tools/build.js
```

Команда пишет:

| Файл | Куда |
|---|---|
| [dist/tokens.css](dist/tokens.css) | Aura, темы Discord и Steam, любая веб-страница. Переменные `--dt-…` |
| [dist/Tokens.cs](dist/Tokens.cs) | Kapsula, core.txt. Класс `DevTxt.Tokens`, собирается встроенным в Windows компилятором |

Что в токенах:

- **Цвета.** Фирменный оранжевый `brand`, системные (`blue`, `green`, `red`…), акцент по умолчанию.
- **Тема.** Тёмная и светлая: фон, поверхности, три уровня текста, разделители, заливки.
- **Стекло.** Три плотности (обычное, под курсором, выбранное) и кромка — как в `Design.cs` Kapsula.
- **Радиусы.** Блок 18, строка 14, элемент управления 11, подсказка 9.
- **Шрифты.** Segoe UI Variable; шкала 26 / 17 / 13.5 / 12.5 / 11.5 / 10.5.
- **Движение.** Одна кривая `cubic-bezier(0.22, 1, 0.36, 1)`, пять длительностей, две пружины.

В CSS светлая тема включается атрибутом `data-theme="light"` на `<html>`; при системной настройке «Меньше движения» все длительности становятся нулевыми.

## Общие элементы

Одни и те же кнопка, переключатель, карточка, вкладки, полоса хода, подсказка и название с подписью `.txt™` — в двух видах:

| Файл | Куда |
|---|---|
| [ui/kit.css](ui/kit.css) | всё, что рисуется в браузере. Классы `dt-…`, подключается после `tokens.css` |
| [ui/Ui.cs](ui/Ui.cs) | Kapsula, core.txt. Классы `DevTxt.Ui`, `Btn`, `Switch`, `Seg`, `Slider`, `Progress`, `Status` |
| [ui/gallery.html](ui/gallery.html) | страница-образец: как всё должно выглядеть. С ней сверяется любое приложение |

Оба файла копируются в приложение как есть и руками там не правятся. Меняется элемент — меняется в обоих файлах сразу.

## Значки

Рисунки всех значков — в [icons/sprites.json](icons/sprites.json): строки из `.` (пусто), `#` (тело) и `E` (глаз). Стиль один на всех: крупные пиксели, один оранжевый цвет, тёмный вертикальный глаз, прозрачный фон.

```bash
node tools/icons.js
```

Команда пишет в `dist/icons` файлы PNG и ICO для каждого значка и общий лист `sheet.png`.

## Хаб

Описание — [hub/PROTOCOL.md](hub/PROTOCOL.md). Коротко: адрес `127.0.0.1:42080`, сообщения JSON, доставка по WebSocket или HTTP.

| Файл | Что это |
|---|---|
| [hub/client.js](hub/client.js) | клиент одним файлом без зависимостей: Node, Electron, страница внутри Discord или Steam |
| [hub/HubLink.cs](hub/HubLink.cs) | тот же клиент для C#: Kapsula и всё, что появится на C# |
| [hub/hub.js](hub/hub.js) | образцовый хаб на Node — для проверок и разработки без Kapsula |
| [hub/test.js](hub/test.js) | проверки клиента и хаба |

Настоящий хаб — внутри core.txt (`src/Hub.cs`); он обязан вести себя так же, как `hub/hub.js`, и проверяется теми же проверками. Через хаб приложения отдают и свои настройки: все они собраны на одной странице в core.txt.

```bash
node hub/hub.js
```

```bash
node hub/test.js
```

## Правила для каждого приложения

1. Цвета, радиусы, размеры шрифта и длительности берутся из токенов, а не пишутся числом в коде.
2. Приложение работает и без хаба, и без остальных приложений.
3. Всё, что приложение сообщает наружу, идёт через хаб, а не через собственный порт.
4. Сгенерированные файлы из `dist/` и общие элементы из `ui/` копируются в приложение как есть и руками не правятся.
5. Название продукта пишется строчными с подписью: `aura.txt™`. У каждого продукта — свой пиксельный значок из `icons/sprites.json`.
6. Кнопки, переключатели и карточки берутся из общих элементов, а не рисуются заново.
